# UX + accessibility audit — apps/web (2026-10-01)

Read-only code audit of every route plus a live render of `/` and `/login`. Paths are relative to `apps/web`. IDs are referenced by the redesign spec (`2026-10-01-strip-board-redesign-design.md`); every **Fix first** item must be closed by the cluster that owns the file.

Priority key: **F** fix first (high impact, low effort) · **P** plan next (high impact, high effort) · **Q** quick improvement · **L** later.
