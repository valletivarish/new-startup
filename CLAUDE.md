# HRVoice — project instructions

## Writing any user-facing text
Every visible string on nexstopp.com and in the HRVoice app (headings, hero, nav, buttons, forms, feature text, empty states, errors, toasts, emails, mobile text) follows the founder's copy standard in `.claude/skills/website-copy/SKILL.md`. Read it before writing or editing copy, and pass it to any agent that writes copy.

In short: write what a real person needs to understand, not what a company wants to sound like. Plain, natural, professional English; say what HRVoice actually does; concrete over vague; buttons say what happens; explain features instead of naming them; never invent features, customers, numbers or promises; leave clear text alone; don't change visual design or typography settings unless asked. Clarity first, specificity second, brand personality third, cleverness last.

Standing rules: no "illustrative"/disclaimer footnotes; no "agent" in HR-facing copy (the AI is "HRVoice"); calls never claim to be human and say they're an automated screening assistant if asked; no voice/telephony vendor names.
